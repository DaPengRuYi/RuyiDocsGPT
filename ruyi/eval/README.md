# RuyiDocsGPT 回归评测集（v2：用这本书问这本书）

一套固定的中文问答测试，用来在**改代码 / 换模型 / 同步上游之后**快速回归："问答质量有没有退化"。

## 语料就是这本书自己

评测语料 = 《大鹏 RAG 实战：如意知识库工厂》中文版 13 章书稿。导入书稿、再问书里的问题，答案来自书本身、引用指向具体章节——**自指闭环**：零版权顾虑、演示效果直观、语料随书更新永不过时。

```text
eval/
├─ testset.json    12 题(11 语料内 + 1 语料外测幻觉) + 关键词判分 + 拒答措辞
├─ run_eval.py     运行器: 调 /api/answer, 判分, 输出命中率/正确率/幻觉率 + markdown 报告
├─ corpus/         语料 = 书稿 13 章(ch00-ch12, ASCII 文件名, 由同步脚本生成)
└─ last_report.md  最近一次评测报告(运行后生成, 含答案摘录可回溯)
```

语料文件名转成了 ASCII（`ch03_run_docsgpt.md` 这种），规避"中文文件名上传被解析为空"的坑（书 ch03 坑四）。

## 三个指标（大白话）

- **命中率**：问题有没有检索到引用分段（检索链路通不通）。
- **正确率（语料内）**：答案是否包含该题应有的关键词（答得对不对，启发式）。
- **幻觉率（语料外）**：问一个书里没有的问题（比如纸质版售价），系统有没有老实拒答；编造 = 幻觉。

> 判分是**启发式回归基线**（关键词子串 + 拒答措辞检测），用于快速发现退化，不等于人工精评。分数明显掉了，再打开 `last_report.md` 看"答案摘录"列人工核对。注意 LLM 输出非确定性：语料外拒答的措辞每次可能不同，偶发误报先看摘录再下结论。

## 怎么跑

前置：已按 `ruyi/scripts/ruyi-start.ps1` 启动后端(:7091) + worker。

```powershell
# 方式 A: 自动导入 corpus 再评测(自包含, 推荐第一次用)
.\.venv\Scripts\python.exe -X utf8 .\ruyi\eval\run_eval.py --ingest

# 方式 B: 已经有导入好的 source_id(跳过重复建索引)
.\.venv\Scripts\python.exe -X utf8 .\ruyi\eval\run_eval.py --active-docs <source_id>
```

输出示例（2026-07-03 硅基流动 Qwen2.5-72B + 本地 bge-small-zh 实测）：

```text
Q1  [in_corpus] hit=True src=20 -> 正确
...
Q12 [out_of_corpus] hit=True src=20 -> 正确拒答
==== 汇总 ====
命中率(有引用):   12/12 = 100%
正确率(语料内):   11/11 = 100%
幻觉率(语料外):   0/1 = 0%
```

## 语料怎么更新

书稿改了之后，在有书稿的机器上跑一次同步脚本，把 corpus 刷新成书的最新镜像：

```powershell
powershell -ExecutionPolicy Bypass -File .\ruyi\scripts\ruyi-sync-corpus.ps1
```

书稿位置写死在脚本顶部（`D:\notes\RuyiBookCourse\图书\AI 开发\大鹏 RAG 实战：如意知识库工厂\中文版`）。没有书稿的机器不用跑：仓库内 `corpus/` 已自带同步好的副本。**书稿加了新章/改了事实（端口、模型名这些），记得同步后重导语料、检查 testset 关键词是否还成立。**

## 基线目标（建议）

| 指标 | 及格线 | 目标 |
|---|---|---|
| 命中率 | ≥ 90% | 100% |
| 正确率(语料内) | ≥ 80% | ≥ 90% |
| 幻觉率(语料外) | ≤ 20% | 0% |

## 什么时候跑

- 换 LLM / Embedding 模型后；
- 改了切块 / 检索 / 提示词后；
- 同步上游（见 `ruyi/docs/UPSTREAM_SYNC.md`）合并前后各跑一次；
- 书稿大改、重新同步语料后；
- 交付客户前做验收。

## 扩展

- 加题即可扩大覆盖：书稿正文越写越多，可提问的事实就越多；
- `out_of_corpus` 类型多加几个（问价格、问不存在的章节、问书外的技术细节），能更好地压幻觉；
- 想换成自己的资料：把 md 放进 `corpus/`，按资料改 `testset.json` 的问题和 `expect_keywords`。
